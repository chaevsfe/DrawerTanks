# Drawer Tanks

Fluid storage add-on for [Storage Drawers](https://github.com/chaevsfe/StorageDrawers).
Tanks in the drawer style, sharing the same upgrade progression, exposing standard
fluid APIs so pipes from BuildCraft, Create, Tech Reborn and others connect directly.

Requires Storage Drawers 19.1.8 or newer. Minecraft 26.2, Fabric and NeoForge.
